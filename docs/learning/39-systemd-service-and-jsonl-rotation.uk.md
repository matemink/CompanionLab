# Керований сервіс і ротація JSONL

## Навіщо це потрібно

Ручний запуск скрипта придатний для bench-тесту, але не для onboard
комп'ютера. Після перезавантаження Raspberry Pi процес має піднятися сам,
працювати без `root`, пережити відсутній під час старту Pixhawk і не заповнити
SD-карту телеметричними логами.

## З яких частин складається рішення

`deployment/systemd/onboard-autonomy@.service` описує життєвий цикл процесу.
Символ `%i` є параметром шаблонного unit-файлу: для
`onboard-autonomy@igor.service` він перетворюється на `igor`. Тому один і той
самий unit запускається від правильного Linux-користувача.

`scripts/install_onboard_autonomy_service.sh` встановлює пакет у `/opt`,
конфігурацію в `/etc` і створює writable state-каталог у home користувача.
Конфіг не перезаписується під час оновлення пакета.

`scripts/run_onboard_autonomy_pi.sh` знаходить один Pixhawk, формує аргументи
runtime і передає потік JSON у `python/rotate_jsonl_logs.py`.

`python/rotate_jsonl_logs.py` працює як streaming sink: кожен рядок одразу
пише у файл та дзеркалить у stdout для `journald`. Коли файл досягає ліміту,
відкривається наступний; найстаріші файли видаляються за лімітом кількості або
сумарного розміру.

## Важливі деталі

- `set -euo pipefail` робить помилку будь-якої частини pipeline помилкою
  всього launcher, після чого `systemd` може коректно перезапустити сервіс.
- `Restart=on-failure` не приховує нормальну ручну зупинку, але відновлює
  процес після помилки.
- `StartLimitIntervalSec=0` не дає `systemd` назавжди припинити спроби, якщо
  Pixhawk під'єднали через кілька хвилин після старту Pi.
- `NoNewPrivileges`, `ProtectSystem=strict` і порожній
  `CapabilityBoundingSet` зменшують наслідки помилки в runtime.
- Найновіший лог зберігається навіть тоді, коли один його JSON-рядок більший
  за ліміт. Так ми не втрачаємо єдиний діагностичний запис через політику
  очищення.

Це розділяє відповідальність: C++ runtime займається автономією та MAVLink,
Python оформлює файловий потік, shell збирає конфігурацію, а `systemd` керує
процесом операційної системи.
