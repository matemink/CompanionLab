# AprilTag test marker

`tagStandard41h12-id0.png` is the official pre-generated ID 0 marker
from `AprilRobotics/apriltag-imgs`, pinned to commit:

```text
f3fd9a7add5bfd82a886fc65240fdb8e3c9ac5a1
```

Source:

```text
https://github.com/AprilRobotics/apriltag-imgs
```

SHA-256:

```text
ad5bc161c157634f05afcfd3cfba34334b9303609dd3afc9c000b86e031da02a
```

Open `show-tagStandard41h12-id0.html` to display the tiny source PNG
with nearest-neighbor scaling and a white quiet zone.

`tagStandard41h12-id0-90mm-a4.svg` embeds the same pinned PNG in an A4
print target. Its 162 mm rendered image preserves the family's 9 cells;
the 5-cell span between the detector corners is therefore 90 mm. Measure
the marked span after printing and pass the measured value to
`--apriltag-size-mm`.

For normal desktop printing, use
`tagStandard41h12-id0-90mm-a4-300dpi.png`. It is the same A4 target
rasterized at 2480 x 3508 pixels and 300 DPI. Print it at actual size
(100%), never fit-to-page, and verify that the 100 mm reference line is
100 mm on paper.
